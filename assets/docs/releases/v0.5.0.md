# Neiroha v0.5.0

## Highlights

- **Web workspace.** Use the original provider manager, voice banks, and Quick TTS in a browser. SQLite saves settings and voice definitions. OpenAI Speech audio plays as it arrives and stops on cancellation. Completed audio remains available in the current tab until it closes or reloads.
- **Streaming synthesis.** Start supported audio before generation completes in Quick TTS and the novel reader. The local API supports incremental PCM. Cancelling an in-flight request discards incomplete audio.
- **Novel and long-form role assignment.** Review AI-proposed roles against the original text, bind characters to voices, and protect confirmed or locked assignments. Configure role models and prompts per workflow.
- **macOS builds.** Separate Apple Silicon and Intel DMGs include the app and its runtime. This release adds recording support and updates playback and application lifecycle handling.
- **Database upgrades.** SQLite migrations are organized by version and tested against historical schemas. Desktop databases upgrading to schema v33 get a pre-upgrade backup.

## Download and run

Download the archive for your platform from this release. For the Web workspace, extract `neiroha-Web-v0.5.0.zip` and serve the extracted files over HTTP(S). Use a provider that allows requests from the site's origin. See the [Web guide](https://github.com/Neiroha/Neiroha/blob/v0.5.0/assets/docs/web-preview-zh.md) for compatible features and server settings.

You can also open the [Wiki Web Demo](https://neiroha.github.io/guide/web-demo) once the Wiki has synced the stable release.

## Known limitations

- The Web workspace covers voice configuration and Quick TTS. Novel reading, production projects, local media tools, and the local API/MCP remain desktop features.
- The macOS DMGs are ad-hoc signed. Microphone and media-key behavior still needs validation on physical devices.
