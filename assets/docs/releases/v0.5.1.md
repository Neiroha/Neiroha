# Neiroha v0.5.1

## Fixes and improvements

- **Provider error reasons.** When a GPT-SoVITS backend returns a JSON error, Quick TTS shows its message with the HTTP status, for example `HTTP 500: English tokenizer is unavailable`. Empty bodies, non-JSON responses, and connection failures keep the general error. ([#10](https://github.com/Neiroha/Neiroha/issues/10))
- **Loop and download in the player.** The player bar can loop the current clip and save a copy of the generated audio. The loop setting is remembered. Dialog sequences and the novel reader still move on to the next clip. On desktop, Quick TTS history entries can also be downloaded directly. ([#5](https://github.com/Neiroha/Neiroha/issues/5))
- **Web model compatibility.** Before generating, the Web workspace checks that the role's model and protocol work in a browser. OpenAI roles default to Speech models. Realtime models that were selected explicitly get their own prompt. Voice, reference audio, and provider problems each get a separate message. The streaming choice moved to the role's voice settings, and the Quick TTS title shows the current mode. ([#9](https://github.com/Neiroha/Neiroha/issues/9))
- **More streaming providers.** Quick TTS and the local Speech API can play PCM as it arrives from Gemini 3.8 TTS, ElevenLabs, MiniMax, MiMo V2.5 preset voices, and Azure Speech. Azure endpoints accept a region shorthand such as `eastus`.

## Download and run

Download the archive for your platform from this release. For the Web workspace, extract `neiroha-Web-v0.5.1.zip` and serve the extracted files over HTTP(S). See the [Web guide](https://github.com/Neiroha/Neiroha/blob/v0.5.1/assets/docs/web-preview-zh.md) for compatible models and server settings.

## Known limitations

- OpenAI Realtime is not yet available in the Web workspace. Browser access requires a backend that issues short-lived credentials. OpenAI plans to retire the current Speech models on 2027-01-06.
- The macOS DMGs are ad-hoc signed. Microphone and media-key behavior still needs validation on physical devices.
