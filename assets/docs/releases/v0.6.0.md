# Neiroha v0.6.0

## Highlights

- **AI services by capability.** Providers now expose separate capabilities: speech, language models, transcription, translation, realtime, voice conversion, and music. One AI services page lists providers, each capability's default model, and the model order. Each provider's editor has a tab per capability, can add models from the public catalog or from your account, and runs a capability check. Language model facts come from models.dev, with LiteLLM as a fallback.
- **New providers and models.** Native Gemini language, transcription, and Live models; Gemini Lyria songs; MiMo speech recognition; a local Neiroha RVC voice conversion server; voice discovery and reference cloning for Irodori. Self-hosted servers can declare their voices and formats with `.well-known/neiroha-capabilities` v2.
- **Character processing chains.** A character can run steps around its voice: an LLM translates or rewrites the line, TTS speaks it, then voice conversion, silence trimming, and an ASR back-check that reports missing or extra speech. With streaming, each sentence goes through the chain as soon as it is ready. The chain runs in every synthesis path, including the local API and MCP.
- **Character chat.** A new page keeps chat sessions with a character. Companion sessions chain transcription, a language model, and the character's own voice; the model can call tools (time, memory) and returns the line with a delivery style and emotion. Live sessions use OpenAI Realtime or Gemini Live, also with tools. Replies can be replayed, and sessions and messages are saved.
- **Song Studio and subtitles.** Generate songs with lyrics or instrumentals, style tags, reference images, lossless WAV, and synced LRC lyrics. Transcribe and translate media into SRT, VTT, or LRC, choosing the ASR, translation, and VAD models per page.
- **Asynchronous speech jobs.** The local API adds `/v1/jobs`: create, list, cancel, retry, follow progress over SSE, and download the audio. Finished jobs are kept across restarts.

## Interface

- **Light, dark, and auto themes.** Settings → General has a theme switch. Colours and status colours come from one set of theme tokens, so pages read correctly on both backgrounds. Icons use one rounded style.
- **Update check.** About shows the version and checks GitHub for a newer release, also once at startup. A dialog names the new version and links to it; you can skip a version or turn the startup check off.
- **Your own sidebar.** Reorder the pages and hide the ones you do not use, such as Song Studio or Subtitles.
- **Voice bank and quick test.** The voice bank has three columns with the quick test in the middle; the composer grows from one line, Enter generates and Shift+Enter adds a line. Model pickers are searchable.
- **Desktop window.** On macOS the title bar blends into the app and the window keeps its size. On Windows the caption buttons sit right of the sidebar. Page headers move the window.

## Fixes

- Quitting no longer crashes in SQLite or flutter_soloud and no longer hangs on open database streams.
- OpenAI never receives a character name as its voice, and a preset voice character always has a voice the model offers.
- Azure speaks each voice in its own locale and accepts streamed PCM labelled `audio/basic`.
- OpenAI Speech models retire on 2027-01-06: affected characters are flagged and can be moved to `gpt-realtime-2.1-mini` in one step.

## Upgrading

The database moves to schema v36. The app backs up the database file before migrating. New tables hold per-character settings, capability routing, added models, and chat sessions. Existing data is kept.

## Download and run

Download the archive for your platform from this release. For the Web workspace, extract `neiroha-Web-v0.6.0.zip` and serve the extracted files over HTTP(S). See the [Web guide](https://github.com/Neiroha/Neiroha/blob/v0.6.0/assets/docs/web-preview-zh.md) for compatible models and server settings.

## Known limitations

- OpenAI Realtime is not yet available in the Web workspace. Browser access requires a backend that issues short-lived credentials.
- The macOS DMGs are ad-hoc signed. Microphone and media-key behavior still needs validation on physical devices.
- The update check opens the release page; downloading and installing is still manual.
