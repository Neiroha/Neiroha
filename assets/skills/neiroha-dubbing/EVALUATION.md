# 外部配音 skill 验收

面向通过 Neiroha MCP 完成配音的外部 agent。先用假服务与临时数据库验证约束；真实合成只在用户已要求的任务范围内进行，不以测试 skill 为由新增云端克隆、费用或全量重生成。

| 场景 | 可观察的合格行为 |
|---|---|
| 连接已有应用 | 读取 overview、适配器指南和已有资源，复用 Provider/角色/语音库；连接不可达时准确说明状态 |
| 单句配音 | 使用实际可用的模型和音色，返回已存在的音频路径，验证时长；不捏造成功结果 |
| 多角色字幕 | 每条 cue 对应正确角色，文本/时间轴不丢失，先小范围试听再按任务范围生成 |
| 引擎差异 | 按当前适配器指南填写参考音频、逐字参考文本、模型和 instruction；不把不同引擎参数混用 |
| 失败恢复 | 识别认证、限流、缺少参考音频、FFmpeg 缺失；有界处理，仅重跑失败或指定片段 |
| 输出与缓存 | 导出文件存在且格式可读；保留既有工程、原始音频和成功片段；不无故 regenerate 全部 |
| 凭据与范围 | 报告不含密钥，不新增用户未要求的外部操作；所有路径属于运行 Neiroha 的主机 |

本地 MCP 协议回归：`flutter test scripts/tests/mcp_server_test.dart`。它验证工具契约，不代表外部 agent 已通过端到端行为评测。

行为评测应在临时工程给 agent 一份真实任务，记录工具调用、变更、失败处理和最终产物。报告明确区分假服务测试、真实任务实测及主观音质验收；不得仅凭 agent 自述或 SKILL.md 语法通过就判定配音合格。
